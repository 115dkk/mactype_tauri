# Logos

`mactype-icon.png` is the MacType product icon, a 64×64 full-colour raster (`control-center/public/mactype-icon.png`). It has no single ink and no vector master in the repository.

- Title bar: 18px beside the product or page title. Classic product lockup: 32px beside "MacType" over a muted "Control Center".
- Show it at its own colours on any surface. Never recolour, outline, redraw or place it on a coloured block, and never pair it with a wordmark other than the plain text "MacType".
