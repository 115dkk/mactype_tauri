# AGENT.md — non-Claude agent entry point

This file applies to non-Claude coding agents working in this repository.

1. Read and follow `CLAUDE.md` for repository operations, worktrees, branch
   policy, CI, releases, upstream hygiene, security boundaries, and repository
   quirks.
2. On `codex/alpha-plus-dll`, the branch charter at the top of `CLAUDE.md`
   takes precedence over its ordinary contribution funnel.
3. The Korean writing-style rule in the `Communication rules` section of
   `CLAUDE.md` is Claude-only. Non-Claude agents must not load or apply
   `chegyejeog-chulonja-v4-style` unless the user explicitly requests it.
   Follow the active system, developer, and user communication instructions
   instead.
4. All other communication and upstream-contact restrictions in `CLAUDE.md`
   still apply, including the ban on contacting upstream without an explicit
   user request.
